# WorkHub

Aplicación Windows para organizar cuentas web, IA, documentos locales y vistas paralelas. El acceso directo ejecuta WorkHub.exe sin consola.

**Actualizar programa → Buscar actualizaciones → Descargar e instalar**. La URL de latest.json es configurable; también se admite un ZIP local. El paquete Windows completo es para instalaciones nuevas o reparación. No se publican los datos de usuario.

Fuentes: React, Electron, Node y un pequeño lanzador Win32 compilado en CI. Consultar BUILD.md y DATOS.md.

La aceptación en la PC del usuario queda pendiente hasta confirmar instalación, reinicio y conservación de sesiones.
